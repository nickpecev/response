# Aftermath

**Emergency Response Intelligence**

*Reconstruct incidents. Analyze responses. Improve what happens next.*

Aftermath is an interactive emergency-response analysis platform designed to help emergency service organizations evaluate their responses to past incidents and identify opportunities for improvement.

By combining data from various sources, Aftermath builds an interactive map of an emergency. Users are able to explore events over time, investigate response delays, and analyze how emergency services utilize their resources.

## Overview

Emergency response operations generate information across multiple systems, including dispatch logs, GPS tracking, communications, weather records, and geographic databases. Analyzing these disconnected sources after an incident can be difficult.
